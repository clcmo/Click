Click Código no GitHub

Marque onde você esteve.

O Click mostra o mapa, encontra sua localização e deixa um marcador a cada foto que você tira.

Baixar o APK Ver no GitHub Como funciona

Como funciona

  1. Abra o mapa

    O Click pede acesso à localização e acompanha onde você está.

  2. Toque em Checkin

    Sem sinal de GPS, o app avisa e usa a Av. Paulista como ponto de partida.

  3. Tire a foto

    Ao confirmar a foto, um marcador com o horário aparece no mapa.
